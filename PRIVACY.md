# Privacy Policy — UniRate Currency Converter

_Last updated: 2026-10-05_

UniRate Currency Converter is designed to collect as little as possible.

## What the extension stores

- **Your UniRate API key** and your **last-used currency preferences** (from/to
  currency, API base URL) are stored locally in your browser using the
  browser's `storage.local` API. They never leave your device except as part of
  the API requests described below.

## What the extension sends, and to whom

- When you convert a currency or load the currency list, the extension makes
  `GET` requests to the **UniRate API** at `https://api.unirateapi.com`,
  including your API key and the currency codes/amount you entered. This is the
  only network destination the extension contacts.
- The extension does **not** send your data to the author or any third party,
  and contains **no analytics, tracking, or advertising**.

## What the extension does NOT do

- No browsing history, page content, cookies, or personal information is read or
  collected.
- No data is sold or shared.
- No remote code is loaded or executed — the extension ships as static files.

## Data handled by UniRate

Requests you make go to UniRate (unirateapi.com), whose handling of API requests
is governed by their own terms and privacy policy. See
[https://unirateapi.com](https://unirateapi.com).
